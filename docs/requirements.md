# 課題定義・要件
 
## 1. 課題の背景
 
<!-- 「何を作るか」ではなく「なぜ作るか」を書く。
     誰が・どんな状況で・何に困っているかを具体的に。 -->
 
適応障害からの回復期において、日々の体調を定量的に記録・可視化する手段がない。
現状はClaudeとの会話スレッド上で7項目0〜21点のスケールで手動記録しているが、
データの蓄積・振り返り・傾向分析が困難である。
 
## 2. 解決したい問題（スコープ）
 
<!-- このプロジェクトで「解くこと」と「解かないこと」を明確に分ける。
     スコープを絞ることも上流スキルの一つ。 -->
 
### 解くこと
 
- 日々の体調スコア（7項目, 0〜21点）を記録できる
- 記録の一覧・推移を確認できる
- 気象データとの簡易的な相関を確認できる
### 解かないこと（将来の拡張候補）
 
- 他ユーザーとのデータ共有
- 医療機関向けレポート出力
- リアルタイム通知・アラート
## 3. ユーザーストーリー
 
<!-- 「〜として、〜したい。なぜなら〜だから。」の形式で書く。
     3〜5本が目安。優先度をつける。 -->
 
| ID | 優先度 | ストーリー |
|----|--------|-----------|
| US-01 | 高 | 利用者として、就寝前にその日の体調を7項目で入力したい。なぜなら、毎日の記録を習慣化するために入力の手間を最小限にしたいから。 |
| US-02 | 高 | 利用者として、過去の記録を日付順に一覧で確認したい。なぜなら、体調の推移を振り返りたいから。 |
| US-03 | 中 | 利用者として、体調スコアの推移をグラフで確認したい。なぜなら、数値の羅列より視覚的な方が傾向を掴みやすいから。 |
| US-04 | 低 | 利用者として、天気・気圧のデータと体調の相関を見たい。なぜなら、気象条件が体調に与える影響を把握したいから。 |
| US-05 | 中 | 利用者として、行動記録（入浴・食事・外出）も合わせて入力したい。なぜなら、行動と体調の関連を後から分析したいから。 |
 
## 4. 非機能要件

     該当するものだけ記載する。 -->
 
| 項目 | 内容 |
|------|------|
| 対象デバイス | スマートフォン（主）、PC（副） |
| データ保存 | ローカルまたは個人用クラウド（第三者に公開しない） |
| 認証 | 個人利用のため不要、または簡易的なもの |
| パフォーマンス | 特に要件なし（データ量が少ないため） |
| アクセシビリティ | 就寝前の暗い環境で使用するためダークモード対応が望ましい |
 
## 5. 用語定義
 
<!-- プロジェクト内で使う言葉の意味を揃える。
     小さなプロジェクトでも認識のズレを防ぐために有用。 -->
 
| 用語 | 定義 |
|------|------|
| 体調スコア | 7項目の合計点（0〜21）。数値が高いほど状態が良い |
| チェック項目 | 体調を構成する7つの評価軸（各0〜3点） |
| 行動記録 | 入浴・食事回数・外出の有無など、体調以外の日常行動の記録 |
