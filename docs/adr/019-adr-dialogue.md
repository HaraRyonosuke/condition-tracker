# ADR-019: ADR の下書きを対話で作る

## ステータス

proposed

## コンテキスト

ADR は [adr-proposal](../../.cursor/rules/adr-proposal.mdc) に沿って作っている。いまのルールは、Cursor がチャットに選択肢・制約・決定案を示し、受け入れたら accepted にする形である。
一方で [ADR-012](./012-ai-usage-and-generated-code.md) は、判断を自分の言葉で残すことを効く制約にしている。Cursor が選択肢と決定案を先に出すと、ADR の選択肢・制約・決定が Cursor の言葉になりやすい。
ADR の下書きをどう対話して作るかを決める必要がある。adr-proposal は「以後の手順」を ADR を切る対象に挙げており、ADR の作り方を変えることはこれに当たる。

制約は以下の通り。

- 選択肢・制約・決定は自分の言葉で残す（ADR-012）
- 自分が知らない選択肢の漏れは防ぎたい
- 同じ決まりを2か所に置かない。置くと、いずれ食い違う
- `alwaysApply` のルールは、ADR を書かないときも毎回文脈に乗る
- 対話が長くなると、途中の答えが文脈から落ちうる

## 選択肢

### 選択肢A: 問いだけにする

Cursor は案を出さない。本人が言葉にした選択肢・制約・決定を整理して書く。

- 長所: ADR-012 にいちばん合う
- 短所: 本人が知らない選択肢は抜けたままになる

### 選択肢B: 問いを基本にし、本人が出し切ったあとで Cursor が選択肢を足す

選択肢は本人が先に出す。そのあとで Cursor が、抜けている選択肢を出典付きで提案する。採るかどうかは本人が決める。

- 長所: 自分主導のまま、漏れを防げる
- 短所: やり取りが1段増える

### 選択肢C: Cursor が選択肢と決定案を先に出し、本人が選ぶ

いまの adr-proposal の形である。

- 長所: 速い
- 短所: 判断の言葉が Cursor のものになりやすい

## 決定

選択肢Bとする。手順の正は [.cursor/skills/adr-dialogue/SKILL.md](../../.cursor/skills/adr-dialogue/SKILL.md) に置く。

- **案の出し方**: 選択肢・制約・決定は本人に聞く。本人が選択肢を出し切ったあとで、Cursor が抜けている選択肢を出典付きで提案する。採るかどうかは本人が決める。決定案は Cursor から出さない
- **問いの順**: 最初に「もう傾いている案はあるか」を1問聞いて控える。あとはテンプレートの見出し順に聞く。確認と補足は任意である
- **書き始め**: 背景を聞き終えてタイトルが決まった時点でファイルを作る。そのあとは、見出しの答えを確かめるたびに、その見出しだけ書く
- **分担**: adr-proposal には、いつ切るか・番号・テンプレート・ステータスの移し方だけを残す。下書きの作り方は、スキルを指す

## 理由

効く制約は、判断を自分の言葉で残すことと、知らない選択肢の漏れを防ぐことである。
選択肢Aは後者を満たさない。選択肢Cは前者を満たさない。選択肢Bは、本人が先に言葉にしてから Cursor が補うので、両方を満たす。

傾きを先に控えるのは、Cursor が足す選択肢を、傾いた案と比べられる相手にするためである。傾きが見えないまま並べると、ほかの選択肢が比べた形だけになりやすい。決定から先に聞くと、背景と選択肢が後付けの説明になる。

見出しごとに書くのは、最後にまとめて書くと Cursor が全体を自分の言葉で書き直しやすく、長い対話では答えが文脈から落ちうるためである。

ルールとスキルを分けるのは、いつ切るかは常に効いてほしく、どう対話するかは ADR を書くときだけ効けばよいためである。ルールに「決定案を示す」を残したままスキルを足すと、2か所が逆のことを言い、毎回文脈に乗るルールの側に寄りやすい。

## 結果

- ADR の選択肢・制約・決定が、本人の言葉で残る
- Cursor が足した選択肢は、見出しの `（Cursor が提案。出典: …）` で見分けられる
- ADR を作る対話は1段長くなる
- 途中でやめると、`proposed` のまま未完成のファイルが残りうる。ステータスで確定したものと区別でき、要らなければ消す
- adr-proposal の本文と BAD / GOOD を直す

## 確認

この ADR のあとで最初に作る ADR で、次を見る。

- Cursor がチャットで、本人より先に選択肢や決定案を出していない
- Cursor が足した選択肢に、`Cursor が提案` と出典が付いている
- 見出しの文が、対話で確かめた文と同じである

## 補足

- この ADR の方針は、Claude チャットとの壁打ち（ADR-012 が許す、リポジトリを触らない相談）で決めた。選択肢は Claude が出し、本人が選んだ。この ADR 自体は、ここで決めた手順（選択肢B）では作っていない
- 番号は、`archives/` にある 005 と 011 を使用済みとみなし、018 の次とした
