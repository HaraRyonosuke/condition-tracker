# ADR-014: 画面アイコンのセット選定

## ステータス

accepted

## コンテキスト

食事時刻のモーダルで、時刻欄に時計の絵が要る。いま出ているのはブラウザ標準の
`input type="time"` の絵であり、プロジェクトで選んだセットではない。
コピー成功や閉じるなど、あとから絵を足すときも同じ系統に揃えないと、画面が割れる。

絵文字は使わない（[conventions.md](../conventions.md)）。
スタイルは Tailwind CSS 単体であり、daisyUI や Vue 向けコンポーネント庫は載せない（ADR-007）。
色は D3 オリーブ茶で、ライト／ダークが切り替わる（ADR-007）。

制約は以下の通り。

- 線の太さと角が、自分で組むボタンと大きく食い違わない
- 色は `currentColor` で文字色に追従する。セット固有の塗りは持たない
- 食事の時計以外にも、後から数個足せる余地がある
- 見た目を管理画面の製品テーマに寄せない
- 小規模な個人プロジェクトであり、依存の数は低く抑えたい
- 公開リポジトリで、個人利用と再配布ができるライセンスである
- カタログを開けて比較できる

## 選択肢

### 選択肢A: セットを決めない（ブラウザ標準と都度の SVG）

- 長所: 依存が増えない。時計は OS／ブラウザのままになる
- 短所: ブラウザごとに絵が違う。2個目を足すときに系統が決まっていない

### 選択肢B: Heroicons

- 長所: Tailwind 公式の線アイコン。余白の感覚がユーティリティと近い。MIT。Figma ライブラリがある
- 短所: 種類が数百で、後から足すときの選択肢が少ない

### 選択肢C: Lucide

- 長所: 線アイコンで種類が千を超える。MIT / ISC。Vue 向け公式パッケージと Figma プラグインがある。角が丸めで、管理画面の製品感が Tabler より弱い
- 短所: Heroicons ほど Tailwind 公式ではない。線の雰囲気は自分で太さを揃える

### 選択肢D: Tabler Icons

- 長所: 線中心で種類が非常に多い。MIT
- 短所: 管理画面・ダッシュボードの製品感が強い

### 選択肢E: Phosphor

- 長所: 線の太さが段階で選べる。種類が多い。MIT
- 短所: 選定時に公式カタログへ到達できず、見た目を比較できなかった。太さの段階を別途決める必要がある

## 決定

画面アイコンのセットは Lucide とする（選択肢C）。

## 理由

効く制約は、時計以外にも絵を足せる数があることと、管理画面の製品感に寄せないことである。

Heroicons は系統は合うが、数が足りない。
Tabler は数は足りるが、製品感が強すぎる。
Phosphor はカタログに到達できず、比較の根拠にできなかった。
セットを決めないと、ブラウザ標準の時計と後から足す SVG が割れる。

Lucide は線アイコンのまま数が足り、Tabler より製品のダッシュボード感が弱い。
この制約ではこれが最も直接である。

食事時刻の時計は Lucide の [`clock`](https://lucide.dev/icons/clock) とする（[design.md](../design.md) 第7節）。
ほかの画面のグリフは、使うときに選ぶ。npm パッケージを足すか SVG をリポジトリに置くかは、最初のアイコンを足すときに決める。
セットの正は Lucide である。

## 結果

- 画面のアイコン系統は Lucide に揃える。他セットと混在させない
- 絵文字は使わない
- 色は `currentColor`。塗りアイコンを既定にしない
- daisyUI やコンポーネント庫のアイコンは使わない（ADR-007）
- 食事時刻の時計は Lucide の `clock`（[design.md](../design.md) 第7節）
- 公式サイトは [lucide.dev](https://lucide.dev)
