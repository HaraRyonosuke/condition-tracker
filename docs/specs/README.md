# ツール仕様

push 前のリファクタは、先にこのフォルダの仕様を、下の順で差分に当てる。関係するファイルが差分になければ、その仕様は何もしない。そのあと [conventions.md](../conventions.md) 第6節の「push 前のリファクタ」を、同じ範囲に当てる。

範囲の外は触らない。外から見た動きは変えない。

| 順  | 仕様                      | 関係する差分                                 |
| --- | ------------------------- | -------------------------------------------- |
| 1   | [Vue](./vue.md)           | `.vue`                                       |
| 2   | [Tailwind](./tailwind.md) | `class` の指定、または `src/assets/main.css` |

新しいツールの仕様は、この表に足してから push 前の対象にする。
