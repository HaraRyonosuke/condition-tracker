# 一般リファクタ

[conventions.md](../conventions.md) 第6節の「push 前のリファクタ」である。ツール仕様より先に、同じ範囲へ当てる。

## 対象

今回の変更が触ったファイル。範囲の外は触らない。

## 仕様

目的は、読み手が追える形に直すことである。外から見た動きは変えない。

直してよいこと:

- 使っていない変数、import、到達しない分岐を消す
- 名前を、そのものがしていることに合わせる
- 同じ処理が二度以上書いてあれば、一箇所にまとめる
- 一つの関数や部品が二つの仕事をしていれば、分ける
- 置き場所を、その層の仕事に戻す
- コードの繰り返しになっているコメントを消す。理由のコメントは残す

直さないこと:

- 入力と出力、画面の操作、保存やコピーの結果
- 新しい機能、不具合の修正、文言の変更
- 空白や import 順だけの整形
- 範囲の外のファイル
- あとの段で決める形（PascalCase、`use...Store`、ディレクティブのフル形式、テストの書き方）

lint / format が通っていることは、このリファクタが終わったことを意味しない。
