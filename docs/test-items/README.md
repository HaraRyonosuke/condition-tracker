# 総合のテスト項目

本番 URL で人が見る項目を、リリースごとに残す。結果（通った / 失敗 / 未実施）は [releases/](../releases/README.md) の、同じ名前のノートの「確認」に書く。

## 名前

- フォルダ名は、リリースノートのファイル名から拡張子を除いたものにする。機能リリースは `US-03`。項目が変わる再デプロイは `redeploy-2026-08-25`
- ファイル名は、そのリリースで行ったテストの名前にする。総合テストは `総合.md`

## 引き継ぎ

新しく総合テストをするときは、直近の `総合.md` を新しいフォルダへコピーし、そのコピーに項目を足す、または直す。空の一覧から始めない。

項目が変わらない再デプロイは、フォルダを増やさない。見る項目は直近の `総合.md` のまま、結果だけリリースノートに書く。

いまの直近は [US-03/総合.md](./US-03/総合.md) である。US-01 のフォルダは無い。US-01 の項目は、この初版に含めてある。
