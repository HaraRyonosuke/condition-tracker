# Product Test

US-03 のリリースで見る項目。US-01 のフォルダは無いので、US-01 の項目もこの初版に含む。

結果は [US-03 のリリースノート](../../releases/US-03.md) の「確認」に書く。ここには通った / 失敗を書かない。

## 画面

- HTTPS の本番 URL で画面が開く

## 文面

- 初期は見出し `【日々の気分チェック記録】`。症状は各行 `—/3`。合計は `—/21`。`[行動]` と `[食事]` は `—`。日時にはブラウザのタイムゾーン名が付く
- スコアを1つ選ぶと当該行だけ `X/3`。未完了の合計は `—/21`
- 7項目すべて答えると合計は `X/21`。合計の横に区分は出ない
- スコアまたは行動を変えると、プレビューの日時がその時点になる
- コピーを重ねると、クリップボードの日時は各操作の時点になる

## 行動

- お風呂は「入れた」「入れなかった」、外出は「できた」「できなかった」。未選択は `—`

## 食事

- 朝・昼・夜・間食はそれぞれ時刻が1つ。画面は12時間、文面は24時間の `HH:MM`
- 窓を開いただけ、キャンセル、背景クリックでは文面は変わらない
- 決定で文面に入る。クリアで `—` に戻る
- 値がある枠を開き直すと、その値が出る

## テーマ

- 画面上部のボタンでライトとダークが切り替わる
- 再読み込みで上書きは残らず、OS の設定に戻る

## 再読み込み

- 再読み込みでスコア、行動、食事が消える。`localStorage` に記録もテーマも残らない

## コピー

- 未完了でもコピーは押せる
- 権限があるときは文面がクリップボードに入る
- 権限がないときは「コピーできませんでした。ブラウザの権限を確認してください。」と出る
