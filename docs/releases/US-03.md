## 利用者向け

- 入浴（入れた / 入れなかった）と外出（できた / できなかった）を選べる。未選択は `—`
- 朝ごはん・昼ごはん・夜ごはん・間食は、それぞれ時刻を1つ。画面は12時間、コピーは24時間の `HH:MM`。未設定は `—`
- 食事の窓を開いただけでは文面は変わらない。決定で入り、クリアで `—` に戻る。キャンセルは変えない
- コピー文面に `[行動]` と `[食事]` が足される。スコア部分は US-01 のまま。未完了の合計は `—/21`
- 画面上部のボタンで、オリーブ茶のライトとダークを切り替えられる。記録もテーマの上書きも、再読み込みでは残らない

## 技術

- 公開先は Vercel（ADR-013）。ホスト設定は変えていない
- `642b4f5` の main への push で、既存の CI が `check` のあと本番へ置いた（run [37413517596](https://github.com/HaraRyonosuke/condition-tracker/actions/runs/37413517596)）。追加の再デプロイはしていない
- ビルドは GitHub Actions の Node 26.9.0。時計は Lucide の `Clock`（ADR-016）
- 単体は Vitest。E2E 自動は置かない（ADR-009）

## 既知・注意

- 閉じると入力は消える（ADR-006）。テーマの上書きも残らない
- クリップボードはブラウザの権限に依存する。権限がないと「コピーできませんでした。ブラウザの権限を確認してください。」と出る
- 確認用ブラウザでは、時刻欄のタップで `showPicker` の窓は出ず、ネイティブ入力に切り替わった。決定・クリア・キャンセルはその入力で通った
- 画面の 12／24 切替はない。コピーは24時間の `HH:MM`
