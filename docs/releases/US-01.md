## 利用者向け

- 7項目のスコアを入力し、整形テキストをコピーできる
- 文面は選ぶたびにプレビューされる。未回答は `—/3`、未完了の合計は `—/21`
- コピーは未回答でもいつでもできる。アプリ内には残らない

## 技術

- 公開先は GitHub Pages（ADR-011）。ビルドは GitHub Actions の Node 26.7.0
- プロジェクトサイトのため本番の `base` は `/condition-tracker/`
- 単体は Vitest。E2E 自動は置かない（ADR-009）

## 既知・注意

- 閉じると入力は消える（ADR-006）
- ダークモードはない
- GitHub Pages ではカスタムセキュリティヘッダーを置けない（ADR-011）
- クリップボードはブラウザの権限に依存する。権限がないと「コピーできませんでした。ブラウザの権限を確認してください。」と出る
